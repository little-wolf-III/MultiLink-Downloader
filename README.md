# MultiLink-Downloader
Windows 多网卡下载器，支持最多四路、自动测速选路及 Tkinter 界面。
多链路下载器 v2.1
=================
适用：Windows 10/11，Python 3.10 及以上，安装时保留 Tcl/Tk and IDLE。
只用 Python 标准库，不用 pip 安装依赖。

一、最简单的用法
1. 解压整个文件夹，双击 start.bat。
   如果使用 PyCharm 的虚拟环境，也可在该环境执行：python gui.py
2. 窗口会自动识别当前已连接、有 IPv4 地址的网卡。
3. 填入 HTTP/HTTPS 文件直链，点击“浏览”选择保存文件。
4. “使用链路数”保持“自动”，点击“开始 / 续传”。
5. 程序会检查目标、测速比较组合，选路后开始下载。

“网站”输入栏必须填写文件直链，不是普通网页。
GitHub/Hugging Face 等的可访问文件直链可尝试使用；服务端必须支持 HTTP Range。
不包含网页解析、视频解析、浏览器登录、验证码处理或 Cookie 导入。

二、网卡与自动选择
- 自动列出已连接的 IPv4 网卡；列出来不代表一定能下载，开始后会针对目标检测。
- 点击表格第一列“候选”可排除某张网卡，例如不想消耗流量的手机线路。
- 自动：比较可用候选的单路和多路组合，选择本次实测总速度最高的组合。
  若单路更快，就只用单路。最多同时用四张网卡。
- 手动选 1/2/3/4：在候选中选择对应数量的最快实测组合。
  若通过检测的网卡不足指定数量，会提示错误，不悄悄改成其他数量。
- 想强制使用具体网卡：只保留这些候选，并将数量设置成它们的数量。
- 候选超过四张时：先测每张单路，再取单路最快四张比较组合。
  这属于限定候选搜索，不代表穷举系统里全部网卡的所有组合。
- 每路默认两个 HTTP 连接；四张网卡最多八个连接。
  网卡数量与每张网卡的 HTTP 连接数量是两回事。
- 同一 Wi-Fi/同一上游出口可能共享带宽，两张网卡不一定产生额外带宽。

测速限制：默认每组约 0.7 秒上限的读取窗口，每连接最多读取 512 KiB。
四张候选所有组合的测速响应正文最多约 32 MiB，另有少量探测及请求开销。
每增加一张超过四张的候选，单路测速最多额外约 1 MiB。
慢线路首包和网络超时可能让测速用时超过读取窗口；准备阶段可以暂停。
测速表示当前针对该文件的短测结果，不保证后续网络变化时仍是全局最快。
选择后不会反复穷举组合；下载线程会更新速度估计、隔离持续失败线路和处理拖尾。

三、暂停、续传和退出
- 点击“暂停”，等状态显示“已暂停”再退出。
- 再次输入同一个 URL、选择同一保存路径，点击“开始 / 续传”。
- 可以换参与下载的网卡或数量；程序会重新检测和测速。
- 必须同时保留：文件名.part 和 文件名.multilink.json。
- 续传会核验已保存块的哈希，损坏的块会重新下载。
- 服务端必须提供可靠版本标识（强 ETag 或 Last-Modified），才能跨运行续传。
  没有版本标识的直链可以从头下载，但暂停后不允许冒险续传。
- 下载中关闭窗口，会先请求停止并保存，再关闭，不会立刻杀掉下载线程。
- 网卡插拔或重新连接后，点击“刷新网卡”更新编号和地址，再继续。
- v1.4 的 .dualmeta.json 断点不兼容 v2.1；旧任务请用旧版续完，或换名重下。

四、速度与异常
- 每块默认 128 KiB，线程按完成速度领取新块，快线路自然承担更多数据。
- 最后几个块若被慢线路占住，最快线路可接替请求；仅最先完成的有效块落盘。
- 某条线路持续失败后会停用，剩余已选线路继续；实际使用数量此时可能减少。
- 所有线路不可用会停止并保存断点；恢复网络后手动继续。
- HTTP 429 会停止整个任务，尊重服务端限流；稍后手动续传，不用换网卡绕过限制。
- 分块响应必须是 206，且 Content-Range、长度、版本与请求一致。
- 跨网卡会比较文件大小、版本和头/中/尾样本；异常时不拼接。
- 完成后计算完整 SHA-256；填写可信的预期值时会自动比对。
  未填写预期值时，计算哈希不等于验证了来源真实性。
- 文件已经存在会拒绝覆盖，换保存名即可。
- 如果出现同名 .lock 提示：先确认其他窗口/进程没在下载该文件；
  确认上次异常退出后，可删除该 .lock，再续传。正常退出会自动清除锁。

五、文件说明
- start.bat：Windows 启动器。
- gui.py：Tkinter 界面，工作线程与界面线程分离。
- network.py：网卡发现、IPv4 绑定、HTTP/HTTPS 和 Range 校验。
- downloader.py：测速选路、最多四路下载、拖尾接替、续传和 SHA-256。
- requirements.txt：运行环境说明，无第三方运行依赖。
- 测试报告.txt、tests/：测试范围、测试代码及本次云端结果。
- 下载完成会生成“文件名.report.json”，包含实际选路、测速和校验结果。

可选命令行（界面用户无需使用）：
python downloader.py --list
python downloader.py --url "https://example.com/file.bin" --out "file.bin"
python downloader.py --url "https://example.com/file.bin" --out "file.bin" --interfaces 9,12,15,18 --count 4
